Q-1. CLI VS GUI

CLI(Command-line-Interface)
    A CLI is an interface where users interact with a computer or program by typing commands.
    It does not use graphics or buttons; every thing is text based.

Features of CLI:
  ->  Requires typing exact command
  ->  Lightweight and fast
  ->  Gives full control over the system
  ->  Often used by developers, system admins, and advanced users

Examples:
  ->  Windows Command Prompts (cmd)
  ->  Linux Terminal (bash, zsh)
  ->  Git command line

Pros:
  ->  Fast and experience users
  ->  Low system resources
  ->  Can automate tasks with scripts

Cons:
  ->  Steep learning curve for beginners
  ->  Mistyped commands can cause errors

2. GUI (Graphical User Interface)

  A GUI is an interface where users interact using graphics, buttons, icons, and menus instead of typing command.

Features of GUI:
  ->  User friendly and visually appealing
  ->  Easy to learn for beginners
  ->  Use mouse, keyboard, or touchpad

Example:-
  -> Windows Desktop
  -> macOS
  -> Web browser (chrome, firefox)
  -> Mobile apps

Pros:
  ->  Easy to use and intuitive
  ->  Reduce errors
  ->  Visual representation of tasks

Cons:
  ->  Slower for repetitive tasks
  ->  Use more system resources

Summary:
  ->> CLI = Powerful and fast, but requires learning commands
  ->> GUI = Easy to use and visual, but slower for advanced tasks
