# Basics of Terminal

## Overview

This section introduces the fundamentals of working with terminals and shell environments.

It covers the differences between terminals and shells, basic shell commands, filesystem navigation, directory listing, and file and directory management.

It also explores commands for viewing and editing files, understanding the terminal prompt, configuring the Bash environment using the `.bashrc` file, and creating command shortcuts with aliases.

By the end of this section, you will understand how to interact with your development environment efficiently using command-line tools.

## Learning Objectives

- Understand what a terminal and shell are and how they work.
- Learn the fundamentals of interacting with a command-line environment.
- Execute basic shell commands such as `echo`, `pwd`, and `whoami`.
- Navigate the filesystem using the `cd` command.
- List directory contents using the `ls` command.
- Create, copy, move, and delete files and directories.
- Understand file management commands such as `touch`, `mkdir`, `cp`, `mv`, `rm`, and `rmdir`.
- View and edit files using `cat`, `nano`, and `vim`.
- Understand the terminal prompt and its components.
- Configure the Bash shell using the `.bashrc` configuration file.
- Create and manage command shortcuts using aliases.
- Develop confidence in using the terminal for everyday development tasks.

## Key Concepts Covered

- Terminal fundamentals.
- Shell fundamentals.
- Terminal vs. Shell.
- Command-Line Interface (CLI).
- Basic shell commands (`echo`, `pwd`, `whoami`).
- Filesystem navigation (`cd`).
- Directory listing (`ls`).
- File and directory creation (`touch`, `mkdir`).
- Copying and moving files and directories (`cp`, `mv`).
- Removing files and directories (`rm`, `rmdir`).
- Viewing file contents (`cat`).
- Terminal-based text editors (`nano`, `vim`).
- Understanding the terminal prompt.
- Bash configuration (`.bashrc`).
- Shell aliases and command shortcuts (`alias`).
