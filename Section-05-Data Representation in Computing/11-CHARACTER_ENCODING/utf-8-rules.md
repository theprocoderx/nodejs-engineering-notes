## Rules for 2-Byte Characters

UTF-8 Format:

    110xxxxx 10xxxxxx

Valid Unicode Code Point Range:

    U+0080 – U+07FF

Minimum valid 2-byte UTF-8:

    11000010 10000000
    U+0080

Maximum valid 2-byte UTF-8:

    11011111 10111111
    U+07FF

## Rules for 3-Byte Characters

UTF-8 Format:

    1110xxxx 10xxxxxx 10xxxxxx
    11100000 10100100 10000101
    100100000101






Valid Unicode Code Point Range:

    U+0800 – U+FFFF

Except:

    U+D800 – U+DFFF
    (Surrogate Code Points — invalid in UTF-8)

Minimum valid 3-byte UTF-8:

    11100000 10100000 10000000

    U+0800

    11101111 10111111 10111111
