# Data Representation in Computing

## Overview

This section introduces the fundamentals of data representation in computing and explains how computers represent, store, and process different types of data internally.

It covers the commonly used number systems, including decimal, binary, octal, and hexadecimal, along with their representations, conversions, and practical applications.

It also explores digital data units, how binary data is physically represented in computer hardware, and why different number systems are used in computing.

Additionally, this section introduces character sets and character encodings, including ASCII and Unicode. It explores UTF-8 in depth, Unicode planes, differences between UTF-8, UTF-16, and UTF-32, and important concepts such as Byte Order Mark (BOM) and endianness (Big Endian and Little Endian).

By the end of this section, you will understand how numerical and textual data are represented at the binary level, establishing an important foundation for understanding JavaScript, Node.js Buffers, file encoding, and data processing.

## Learning Philosophy

Develop a strong understanding of how computers represent and interpret data before moving toward more advanced programming concepts.

Focus on understanding number systems, binary representation, character encoding, and how textual data is stored and processed internally.

Pay particular attention to the relationship between binary data, bytes, Unicode, and character encodings. These concepts are especially important when working with JavaScript strings, Node.js Buffers, file systems, streams, and network communication.

Learn through manual calculations, practical conversions, experimentation, and understanding the underlying mechanisms rather than simply memorizing formulas or definitions.
