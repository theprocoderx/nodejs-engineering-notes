# Basics of OS

## Overview

This section introduces the fundamentals of operating systems and explains how computers manage hardware resources, execute programs, and handle processes and threads.

It covers CPU architecture, processors, cores, operating systems, kernels, processes, threads, concurrency, and parallelism.

It also explores environment variables, Windows Subsystem for Linux (WSL), filesystem paths, executable files, file permissions, and how commands are executed by the operating system.

Additionally, this section introduces important methods and properties of the Node.js `process` object, helping establish a deeper understanding of how Node.js applications interact with the underlying operating system.

By the end of this section, you will have a foundational understanding of operating system concepts that are essential for learning Node.js and backend development.

## Learning Objectives

- Understand the fundamentals of CPU, processors, and CPU cores.
- Understand what an operating system is and how the kernel works.
- Learn what a process is and how the operating system manages processes.
- Understand threads and their relationship with processes.
- Differentiate between concurrency and parallelism.
- Understand whether a process can exist without a thread.
- Learn about worker threads and how to debug them.
- Understand environment variables and their importance.
- Learn how to set, access, and use environment variables.
- Install and configure Windows Subsystem for Linux (WSL).
- Understand the differences between Windows and Linux filesystem paths.
- Learn what executable files are and how they work.
- Understand file permissions and how they are managed.
- Learn how commands are located and executed by the operating system.
- Explore important methods and properties of the Node.js `process` object.
- Understand how Node.js applications interact with the operating system.

## Learning Philosophy

Develop a strong understanding of how operating systems work before moving toward advanced Node.js concepts.

Focus on understanding how hardware resources are managed, how processes and threads execute, how environment variables are configured, and how the operating system handles commands and executable files.

Pay particular attention to the relationship between Node.js and the underlying operating system, especially when working with processes, environment variables, filesystem operations, and worker threads.

Learn through practical experimentation, command execution, debugging, and understanding the underlying mechanisms rather than simply memorizing concepts.
