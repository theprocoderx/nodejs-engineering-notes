What NPX does?.
Searches for a file and execute it.


Search Step-1 ->

Searches for package.json in root/current working directory.

          Searches for name key in the json file.
          Search for bin key in the json file

Search Step-2 ->
          Searches for "node_modules/.bin/hello" in current working directory
          and execute this file.

Search Step-3 ->
          Searches for hello in global npm folder
          and execute this file

Search Step-4 -> 
          Searches for hello package in npx_cache
          and execute this file

Search Step-5 -> 
          Searches for hello package in npm registry
          
          Prompts to install the package if found
          Downloads and install
